Local Setup Instructions

Note: This is a PHP/MySQL application. GitHub Pages shows a static version. For full functionality, follow the setup instructions below.

Installation Steps

  1. Install XAMPP and start Apache and MySQL servers
  2. Clone or download this repository
  3. Copy the project folder to xampp/htdocs directory
  4. Import the database file from database_file folder into phpMyAdmin
  5. Open your browser and navigate to localhost/capitalconnect

Database Setup

  • Create a database named rn_8164 in phpMyAdmin
  • Import the SQL file from the database_file directory
  • Update database credentials in PHP files if needed
